# Kosong

**Kosong** adalah ruang sederhana untuk memulai dari nol.

Repositori ini menjadi tempat untuk menaruh ide, eksperimen, dan hal-hal baru—tanpa harus menentukan semuanya sejak awal.

## Tujuan

- Menjadi titik awal untuk ide dan proyek baru.
- Menyimpan catatan atau eksperimen secara bertahap.
- Tetap sederhana dan terbuka untuk berkembang.

## Mulai

Tambahkan ide, file, atau dokumentasi yang ingin kamu kembangkan di repositori ini.
